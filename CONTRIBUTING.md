# Contributing

Bug reports, ideas and pull requests are welcome. The app is meant to stay
minimal: one screen, no settings, everything readable at a glance. Please open
an issue first for larger changes.

## Setup

Requirements: Node.js 24.

```sh
npm ci
npm run serve        # http://localhost:8080
```

There is no build step; the files in `src/` are the app.

## Before a pull request

```sh
npm run lint:fix     # Biome: format and lint
npm run check        # what CI runs
```

Check the layout on a small phone (375 x 667) and a large one (412 x 915) in
the browser's device toolbar: nothing may scroll or overflow.

## Notes

- New files under `src/` must be added to `SHELL` in `src/sw.js` (offline
  cache) and, for modules loaded at startup, as `modulepreload` in
  `src/index.html` (avoids an import waterfall).
- `src/js/borders.js` is generated by `npm run borders`; do not edit it.
- Keep `src/js/model.js` free of I/O and DOM access.
- UI text is German, code and comments are English.
